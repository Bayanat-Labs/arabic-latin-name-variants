# Changelog

## 0.1.0 (2026-11-01)

First release: dump stream and name filter, string cleaning and script checks, Buckwalter and ALA-LC
fields, consonant-skeleton relation filter, compound-aware token alignment, token_variants and
clusters tables, the name_matching_bench test set and four baselines, and three checks on people's
name strings (a lexicon and structure filter, a same-name rule, a separate check). Built from the Wikidata
JSON dump of 2026-10-26.
